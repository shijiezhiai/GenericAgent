# 代码审查知识库（code-reviewer）

> 本专家按需读取。沉淀审查中反复用到的 checklist 与避坑点。
> L2 层：不每轮注入，模型按 L1 指针（行数/大小）判断是否 file_read。

## 正确性
- [ ] 边界：空集合 / 单元素 / 超大 / 负数 / off-by-one
- [ ] 空值与可选：None / 空串 / 缺省值分支
- [ ] 并发：竞态 / 可见性 / 锁粒度 / 死锁
- [ ] 资源：文件 / 连接 / 锁 必有释放（try/finally 或 with）
- [ ] 错误传播：异常是否吞掉、是否丢失上下文、是否泄露实现细节给上层

## 可维护性
- [ ] 命名是否表意（禁 data/tmp/process 等无意义名）
- [ ] 圈复杂度 >10 需拆分
- [ ] 重复逻辑 >3 处需抽象
- [ ] 隐藏假设是否注释或断言

## 性能
- [ ] 循环内 I/O / 重复计算
- [ ] N+1 查询 / 全表扫描
- [ ] 不必要的内存拷贝 / 全量加载

## 安全
- [ ] 注入（命令 / SQL / 路径）
- [ ] 敏感信息日志泄露
- [ ] 权限校验遗漏
